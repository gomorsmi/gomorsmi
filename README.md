### Focus areas

- **Cloud architecture reviews:** multi-cloud assessments with inventory, diagrams, and prioritized recommendations
- **FinOps and cost optimization:** commitment strategy, rightsizing, and billing structure
- **AI infrastructure:** visibility into model API, GPU, and managed AI service spend
- **Open-source tooling:** CLI Radars: scanners that turn cloud accounts into actionable cost data

### Open source: Hyperscaler Radar

| Project | What it does |
|---|---|
| `aws-radar` | AWS inventory across regions, exported to CSV and draw.io architecture diagrams |
| `gcp-radar` | Google Cloud project inventory and architecture diagrams |
| `azure-radar` | Azure resource inventory and cost visibility |
| `oci-radar` | Oracle Cloud resource inventory and cost visibility |
| `anthropic-radar` | Anthropic API usage and spend visibility |
| `gemini-radar` | Gemini API usage and spend visibility |
| `openai-radar` | OpenAI organization scan with usage, resources, and service relationship mapping |
